# Number Guessing Game

A simple number guessing game built with Python. The computer randomly selects a number between 1 and 100, and the player tries to guess it.

## Features

- Generate a random number between 1 and 100.
- Give hints when the guess is too high or too low.
- Count the number of guesses.
- Display the total number of attempts when the correct number is guessed.

## Technologies

- Python 3
- `random` module
- `while` loop
- Conditional statements
- User input and basic counting

## Project Purpose

This project was created to practice Python fundamentals, including random number generation, loops, conditional statements, and user input.
